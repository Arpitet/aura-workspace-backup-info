Aura Workspace Backup

A personal desktop backup and restore tool for the account owner’s Aura development workspace.

The tool creates encrypted backups locally and copies them to a dedicated folder in the Google Drive account the owner authorizes. It can check and restore those backup files. It is not a public file-sharing or account-registration service.

Google Drive access

The tool requests the drive.file permission to create and manage the files and folders authorized for this application. It does not request access to every file in the owner’s Drive.

Backup and restore

Backup contents are encrypted by restic before upload. rclone transfers the encrypted repository using the owner’s OAuth authorization. Google Drive still processes account, permission and transfer metadata needed to provide its service.

Operator and support

This is a personal-use tool maintained by its account owner. Use the support email displayed on the Google authorization screen for questions about this OAuth application.
